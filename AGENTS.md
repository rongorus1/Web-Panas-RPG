## Code comments

- Write every code comment in English.
- Add a comment only when it is necessary: a non-obvious reason, a constraint, a workaround or a magic number. Do not narrate what the code already says, and do not add doc comments that repeat a name or a type.
- Prefer clear names and structure over comments. Delete a comment when the code it explains changes or disappears.
- Product copy and content strings stay in Spanish; this rule applies to comments only.
